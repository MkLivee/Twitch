Les défis du chat

Vous avez les idées. J’assume les conséquences.

  1. 1Découvre un défi dans le catalogue ci-dessous.
  2. 2Propose le tien sur Discord. Une contrainte, un objectif, une arme imposée : à toi d'imaginer.
  3. 3Attends la validation du streamer. Une proposition n'est pas automatiquement acceptée.
  4. 4Regarde-le tenter pendant un live. Si le défi est validé, il passe devant la caméra.

Les règles du jeu et le respect des autres joueurs priment sur tous les défis.

Chaque défi porte un statut : Idée, Validé, Réussi ou Échoué.

  • Statut : Idée

    Une arme, beaucoup d'excuses

    • Jeu : Valorant
    • Difficulté : Difficulté moyenne

    Une arme imposée pendant une manche. Le chat choisit, je fais de mon mieux, et les excuses attendront la fin de la partie.

  • Statut : Idée

    Objectif anti-panique

    • Jeu : Valorant
    • Difficulté : Difficulté moyenne

    Un objectif annoncé avant la partie, et je tente de m'y tenir jusqu'au bout. Le but : garder son sang-froid, même quand ça se complique.

  • Statut : Idée

    Le choix du chat

    • Jeu : Autre jeu
    • Difficulté : Difficulté variable

    Une contrainte proposée par la communauté, sur un autre jeu que Valorant. Elle doit d'abord être proposée sur le Discord, puis validée.
